# 嘉立创 EDA 工程助手

用户给工程路径、参数和连接意图；助手负责实际库查找、内部身份、位置/朝向和局部路径。不要让用户提供UUID、会话ID、脚本或逐根画线。沿用户已授权范围连续执行；范围不清时先读取，再只询问影响设计的缺失条件。

## 先选择工作流程

- 环境/已有工程检查：doctor → open_project（隔离只读副本）→ inspect_project → read_document/read_connectivity/read_pcb_routing。未知工程身份先发现，随后按真实绑定核对；结束回收自有读取上下文。
- 新小型原理图/首次PCB同步：create_work_project 或 derive_work_project → draw_schematic → verify/preview → sync_pcb → 原生复核 → verify → 布局/规则/局部或受限路由 → finish_work_project。具体边界见 [日常使用与状态处理](references/usage.md)。
- 已完成PCB局部孔/线/位号/EP钢网：incremental_pcb，从closed成品派生，plan → apply/verify → finish。工程内独立钢网封装仍有“仅所选实例”原生步骤，不写共享/全局库。
- 单脚测试点：schematic_eco，默认 single_point 模式，沿已验收P4-D流程。
- 常规两脚R/C新增或兼容换料/改接：schematic_eco，mode=passives；详见 [阻容增量操作](references/passives.md)。
- 制造交付：从最终成品 export_manufacturing，一次新导出；未知导出仅复核已捕获文件，不重新导出充数。

## 当前共同边界

通常只有一个本任务可见窗口；新写必须由正式入口派生到新目录。来源成品、closed journal、旧交付和旧失败记录保持。不能手改journal解锁、打开原件当工作副本、整页/整板源码替换或用任意JS绕过公共入口。所有实际内部身份来自当前返回值和现场读取，不能把例子的身份用于新工程。

位号/料号/名称不是唯一身份；核对 uniqueId、原生器件/符号/封装来源、全部脚号/焊盘及实际网络。模板机制可能优先采用当前工程内模型，应读完整源与真实变换，保留显式PCB本地封装覆盖，尤其不能在同步中意外替换独立工程封装。

mm输入，PCB原生+Y向上；原理图API10mil、PCB API mil、存储Y与API角度差异由适配器处理。真实尺寸来自模型，不按封装名或设备外形推测焊盘间距。旋转/镜像、模型原点、当前图层必须在写前核实；未支持几何拒绝。

## 界面依赖与未知结果

工具返回 needs_ui 时，先核对返回的精确工作窗口/工程/目标。宿主有界面能力就完成明确原生步骤，再调用同请求验证；用户已授权的原生复核不额外逐项审批。缺少界面能力或Mac锁定时保留状态并给出一个具体下一步，继续不依赖界面的工作。

原生导入 true 只表示复核/读回待完成。等待并查看准确窗口中的增删/属性/焊盘网络清单；只应用计划项，关闭旧导线自动改名和设计规则变更。pending复核期间不通过预览/原理图读取切页，不重开、不再次导入。复核可能迟于API回执出现，未出现时先保留回执与PCB只读结果。

所有写入有持久意图和结果记录。重复请求复用既有动作，显式参数冲突/源变更拒绝；pending/unknown不因等待、服务重启或更换requestId而重放。只按具体已实现恢复条件处理，不能泛化旧任务的特殊恢复入口。对应历史条件只在需要时查 [历史记录](references/verified-history.md)。

## 完成与报告

全部引脚网络对应、保守全铜连通、新严格DRC及原规则/非目标全档案核对分别通过，才报告板图完成。保留实际API计数与完整存储计数差异，微线只在完整源和严格包含证据下补充，不删除凑数。

finish要求两端保存、全新磁盘副本/新读取会话完整匹配、来源与现场稳定、读取上下文回收和自有工作窗口关闭。save true 不等于持久化。closed复用先核对当前文件/源/checkpoint/参数和完成证明，不重新打开或改写journal。退出后不为观察再次getApp/AX唤起应用；被动进程检查即可。

原生换料和新磁盘读取的限定差异、内部图元身份映射与原锁定/位号恢复要求见 [阻容说明](references/passives.md)。完整原生几何与删除证明保持；仅已注册的两个预览筛选体允许比较归一化。

报告区分：工具实际执行、逻辑/铜/DRC、视觉/持久化、制造/装配、机器零度/机械/3D、实物性能。Gerber/BOM/CPL生成不表示可下单；孔与钢网/阻焊、裸露EP孔、文字净距及方向待确认项继续保留。只输出本地文件，上传、下单、支付另需用户明确授权。

运行包/开发协议与实际宿主分别报版本和来源。安装后的统一加载由当前任务安排，不因版本目录存在就宣称宿主已加载，不重复要求用户重启。
