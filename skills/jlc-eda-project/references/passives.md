# 常规阻容增量

当前使用 `jlc_eda_schematic_eco mode=passives`，工具数量保持35。范围是单板单页低压双层板、顶层零原点、无极性常规两脚矩形SMT电阻/MLCC，每阶段1–2目标。新增与修改分别成阶段，避免先生成最终接法后声称验证了改接。值/料号必须来自真实库；电阻限普通膜电阻，电容限已核实的X7R/X5R/C0G/NP0。不能只改文字。

正交0/90/180/270°由真实模型变换、脚号与当前规则预检；底层镜像、非零原点、极性器件、不同焊盘几何换封装和任意删件拒绝。实机覆盖与离线方向检查分别报告，不将纯变换测试称为实机证明。

## 输入与顺序

1. 给 sourcePath、sourceCheckpointPath（同成品真实closed记录）、新outputDirectory、requestId，phase=derive。内部会话与文档自动发现；同请求未知打开只恢复准确已知窗口，不再次open。
2. phase=parts，candidateSupplierIds查最多4个候选。真实库文件、符号两脚、封装两焊盘、尺寸/原点、参数、供应商/制造商型号和当前工程模板都核实。
3. phase=plan，passiveChanges只包含 additions 或 modifications。助手依需求与读取数据产生全部坐标/路径，用户无需填写。
4. 新增：每颗designator/supplierId/kind、schematic/pcb正交pose、两脚明确已有网、每脚局部connections和labelAtMm。连接可包含同网extraPaths及普通过孔vias；首段必须从真实焊盘出发，当前规则/全部铜预检通过才能写。
5. 换料：每目标designator/supplierId/kind；先证明目标身份与新旧实际焊盘/原点/方向兼容。prepare_replace targetDesignator选中精确实例，原生器件管理器检索实际料号；保留位号/唯一ID、当前符号和当前封装，合并属性目标优先。只替换该实例，然后adopt_replace按模型来源、参数和全档案核验，并在切页前保存原理图。相同型号其他实例与共享模型几何保持；原生预览显示元数据的限定差异另报。
6. phase=schematic创建新增两脚短线/端口，或修改目标一脚原生短线与端口网络。phase=sync只导入一次；原生复核仅应用计划新增/目标属性/目标焊盘网络，随后verify_sync读实际PCB，保存PCB后再切原理图完整核对。
7. phase=complete只放置/锁定新增目标、调整其位号、处理明确旧支路并绘制新局部线/孔。preview/verify分别核对视觉与逻辑/铜/严格DRC/原规则/全部非目标。phase=finish完成保存、新磁盘核对和关闭。
8. 最终成品才生成一次新制造交付；中间新增阶段无需重复生产导出。

## 改接的限制

reconnect声明一个pin、oldNet/newNet（另一已有网）、removeBranches和新connection。当前要求原理图是已完成公共ECO创建的独立短线/端口，旧PCB支路是该closed谱系中有单次创建回执的完整局部支路。计划严格对应每个旧LINE的实际网络/层/宽/端点/ID和原创建证明；不支持任意复杂用户分叉支路的自动识别。

旧支路必须真实删除，新连接必须真实成立，最终完整旧/新网络铜图和DRC通过。不能整体重命名旧铜网络、清空整网、保留旧接法只多加一条线，或借改接改动其他原有铜。器件/焊盘身份、其他脚和其他实例全部保留。

## 原生差异与结果

器件管理器可能保留旧器件为备选、记录新器件/封装名称、增加3D关联属性、重排目标属性显示序号和默认strikeout=false，以及写入两个已实测的封装预览显示筛选记录。只有精确模型来源、位号/唯一ID/姿态/引脚/焊盘几何与全非目标核验通过，才接受对应声明字段。显示筛选的例外不放宽铜、规则、模型几何、其他属性或实例；实际差异单列。

needs_ui：准确原生窗口未完成，保留现场与意图；unlock或完成明确复核后同请求验证。unknown：动作或保持未证实，只读检查和诊断，不重放。failed/unsupported：说明缺少的真实模型/几何/来源证明；尚未写时可换兼容候选重新计划，写后参数冻结。closed：先核对源/checkpoint/成果SHA/保存关闭证明后只读复用，不再显示/打开原工作。


## 已实测的替换与保存行为

原生 PCB 器件替换会保留 uniqueId、封装和锚点，但可能重建组件/属性/焊盘关联的内部 ID。只允许两颗已声明目标按唯一身份及完整属性、pinSwapInfo、焊盘号/原模型和网络一一对应；其他实例/模型/铜/规则仍完整保持。导入后已观察到目标解锁及位号字高恢复默认；complete 必须恢复来源的原锁定与字高，最终不得用临时默认值通过。

V3 原生 models 快照可能包含空体原子删除记录，以及按顺序编号的删除占位记录。保留原始档案；活动记录与删除身份分别核对。仅允许精确旧目标焊盘关联、声明支路 LINE 的删除，旧占位内容按顺序保持，新占位预算等于准确删除的组件/属性/LINE 记录数。不能把空记录当作解析错误后跳过未知内容，不能忽略任意类型的占位。

改接短线的 NET 与网络端口 Name 是两个实际属性。公共入口修改指定短线和来源绑定的 Name 属性，并要求全量逻辑再次匹配，禁止整网改名。已观察的旧 setter 无效果补全只适用于已有 returned 记录、端口 Name 仍旧值且完整其余档案匹配的情况；明确写前类型拒绝保留为拒绝并有全量零变化资格，不标成功。超时和不明写入不重放。

新磁盘上下文会恢复两个已采用的封装预览筛选记录。完整记录比较只对精确已注册的原始/观察到的非几何筛选体作比较归一化，并同时保留原始 SHA、差异、全部几何/逻辑/删除证明及成果文件 SHA；其他记录仍严格比较。此限定不提供任意模型或显示字段忽略。

A9-R1 增加有来源的目标 FOOTPRINT 默认配置登记：精确空名 NET 六字段与 12 项 PRIMITIVE 的完整体，且来源/全部原记录不变、无重复或额外记录。NET 单独证明无类/差分/等长设置，连接映射仍完整比较。恢复和磁盘规范化仅使用已登记前后体与模型锚点；详见仓库 docs/native-preview-defaults.md。
