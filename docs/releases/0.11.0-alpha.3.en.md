# 0.11.0-alpha.3 · Dependency-patched developer preview

A local MCP/Skill developer preview for macOS + JLCEDA Pro 4.1.60, not an official JLCEDA or OpenAI project. Project repository: [aning0922/codex-jlc-eda](https://github.com/aning0922/codex-jlc-eda). These notes describe the scope of software validation; see [Actions](https://github.com/aning0922/codex-jlc-eda/actions) for remote workflow status.

## Changes

- Pin fflate from 0.8.2 to 0.8.3, addressing the identified malformed-ZIP64 synchronous decompression hang.
- Update MCP SDK from 1.30.0 to 1.31.0 within 1.x. Its earlier OAuth advisory did not apply to the current stdio paths; this update still adopts the upstream patched version.
- Add two ZIP64 regressions: a missing required extra field must be rejected, while a valid empty file remains readable. Potentially hanging input runs only in a child with a 1500 ms wall-clock limit.
- Compare all entry names, sizes and content hashes in two existing native/manufacturing ZIPs using old and new versions; results match and the original archives remain unchanged. Real archives are not distributed.
- Preserve all 35 tool schemas, descriptions, annotations and business algorithms, the bilingual READMEs, and recovery/privacy/license guidance. Alpha.1/Alpha.2 assets remain intact.

## Qualification and limits

See the [validation record](../validation.md) for 105 local offline tests, compiled public MCP, source/runtime checks and the full dependency audit. Alpha.3 has not been installed into the actual chat host; no new RC board, native DRC/save cycle or physical test was performed. The last observed host still ran 0.10.0. Alpha.1 had only its 19 installed files checked. The eight-component RC example remains a specification awaiting execution.

Dependency fixes do not establish that all hostile archives are safe or all vulnerabilities have been found. Manufacturing file generation is not production approval; assembly orientation, machine zero orientation, mechanical/3D fit and physical performance still need confirmation.
