# 0.11.0-alpha.3 · 依赖修复开发预览

面向macOS + 嘉立创EDA专业版4.1.60的本地MCP/Skill开发预览；不是嘉立创或OpenAI官方项目。项目仓库：[aning0922/codex-jlc-eda](https://github.com/aning0922/codex-jlc-eda)。本页记录软件验证范围；远端工作流状态请查看 [Actions](https://github.com/aning0922/codex-jlc-eda/actions)。

## 本版变化

- fflate精确升级0.8.2→0.8.3，修复已识别的畸形ZIP64同步解包挂起问题。
- MCP SDK限定在1.x内从1.30.0→1.31.0；其旧OAuth公告不适用于当前stdio路径，本次仍更新到上游修复版本。
- 新增两项ZIP64回归：缺失必需扩展字段须明确拒绝；合法空文件仍能读取。可能挂起的输入只在1500ms墙钟超时子进程执行。
- 两份既有原生/制造ZIP旧/新解包的完整文件名、大小与内容SHA一致，原ZIP未修改。真实归档不随公开包分发。
- 35项工具schema、描述、注解及业务算法保持；保留双语README、恢复/隐私/许可说明，旧Alpha.1/Alpha.2资产没有覆盖。

## 资格与限制

本地105项离线测试、编译公共MCP、源码/运行包及完整依赖审计结果见[验证记录](../validation.md)。没有执行Alpha.3实际宿主安装、RC新板、原生DRC/保存闭环或实物测试。最后实际宿主观察仍为0.10.0；Alpha.1只核对过19安装文件。8件RC内容是待执行规格。

依赖修复不表示可接受所有不可信档案或所有漏洞已被发现。制造文件生成不等于可投产，装配方向、机器零度、机械/3D与实物性能仍需确认。
