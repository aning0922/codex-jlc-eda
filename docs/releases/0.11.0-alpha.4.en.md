# 0.11.0-alpha.4 local candidate (unpublished)

> Historical local A6 candidate / 历史 A6 本地候选。Current source is `0.11.0-dev.a10`; see [development status / 当前进展](../development-status.md). This snapshot was never published.

2026-10-10, compat/eda-4.1.71. The 35 public tools and their input schemas remain unchanged. Published Alpha.3 tags and assets are preserved.

Public read_library_model now prefers official lib_Symbol/lib_Footprint.getDocumentSource. It binds requested library/model metadata and DOCHEAD, reports native 3.0 format, SHA256, version, units, origin and terminal geometry, and distinguishes project-library from external-library sources. Worker content can be unsaved and is not disk-persistence evidence. Missing source, wrong identity, ambiguous terminals and unsupported geometry are rejected. The legacy canvas path is used only when the source API is absent. Current direct geometry support is limited to single-unit symbols and simple hole-free RECT/ELLIPSE/OVAL surface pads; mechanical bodies, 3D, multi-unit and complex pads are not qualified.

The shared native parser removes only a trailing CR on each record line. LF/CRLF inputs remain equivalent; escaped string content and deletion identities are retained. Five targeted tests were added: all 110 offline tests and the unchanged 35-tool compiled protocol snapshot passed.
