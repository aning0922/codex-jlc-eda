# 0.11.0-alpha.2 · Developer preview (draft release notes)

**Local candidate under review; not published. The known fflate runtime issue is unfixed. Complete a focused fix and review before distributing the runtime publicly.**

This release prepares the independent plugin for an understandable bilingual project home and versioned assets: complete Chinese/English READMEs, language links, an original conceptual workflow graphic, a runtime-first quick start, contribution/security guidance, Issue/PR templates and maintainer release steps.

All 35 public tool schemas, descriptions, annotations and business algorithms remain unchanged. Business source changes only report the new version. Packages now go under `release/0.11.0-alpha.2/`, preserving Alpha.1 assets. Alpha.1 installation/resume records remain intact; Alpha.2 is not installed in this round.

## Validation and limits

See the [validation record](../validation.md) for local results. GitHub CI has not run and the RC example has not started. Historical 0.10 editor results and Alpha.1 installed-file matches are not Alpha.2 real-editor qualification. The eight-component RC example remains a specification awaiting execution.

A complete dependency audit identified two advisories: fflate 0.8.2 affects synchronous archive parsing actually used at runtime; the SDK 1.30.0 HTTP OAuth issue does not apply to the current stdio entry points. See [applicability and the minimal follow-up](../dependency-security.md). Dependencies were not automatically upgraded, and a preview label does not waive security review.

## Assets

- `codex-jlc-eda-0.11.0-alpha.2-runtime.zip`: precompiled local plugin, without node_modules or a need for npm install; includes both READMEs, the Skill, licenses and operational documentation.
- `codex-jlc-eda-0.11.0-alpha.2-source.zip`: allowlisted source with lockfile, tests, CI and docs; must be built before use.
- `SHA256SUMS`, `source-manifest.json`, `runtime-manifest.json`, `packages.json`: hashes, sizes and file lists. Each ZIP also has MANIFEST.json.

The qualified target environment is macOS + EDA Pro 4.1.60, with Node ≥20. This is not an official JLCEDA/OpenAI project. Project-owned code, prose and conceptual graphics use MIT; third-party dependencies retain their licenses. Real models, native projects, manufacturing files and historical screenshots are excluded. Generating files does not establish production readiness.

When publication is approved, mark it **Pre-release**, not a stable Latest release. Use the reviewed SHA256SUMS beside the assets. Confirm ownership, attribution and a private security channel before following the maintainer checklist.
