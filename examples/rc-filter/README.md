# 下一轮唯一实例：低压 RC 信号滤波与测试小板

**当前是 OSS-A2 待执行规格，未绘制、未制造、未测试实物。** 不包含预造 journal 或来源不明的模型。输入是同目录 `requirements.json` 的人类需求表，不能直接传给 circuit/工具 schema；助手必须依据现场真实器件与引脚生成工具输入。

## 需求与规模

单页单板、双层、目标 30 × 20 mm，0–3.3 V 信号，无外部电源芯片。J1 输入、J2 输出均为简单两脚连接器；R1=1 kΩ 串联，C1=10 nF 对地，R2=100 kΩ 输出泄放。三个单脚 SMT 测试点分别接 IN、OUT、GND。总计 **8 件、13 引脚、3 网络**；所有引脚均连接，无 NC。

| 网络 | 全部端点（现场必须核对脚号） |
|---|---|
| IN | J1.1、R1.1、TP1.1 |
| OUT | R1.2、C1.1、R2.1、J2.1、TP2.1 |
| GND | J1.2、J2.2、C1.2、R2.2、TP3.1 |

电阻优先 0603、1%；电容为耐压至少 16 V 的无极性 MLCC，优先 0603。选择常规矩形焊盘、原点可核实的模型；不采用裸露 EP、孔中孔、复杂封装或独立钢网。连接器只在初始原理图创建，不执行连接器增量改接。真实料号、库存、价格与模型在执行时重新查，不在规格中冻结。

信号源阻抗假设 ≤100 Ω，测量负载 ≥1 MΩ。忽略外部负载且源阻抗为零时，直流增益为 100k/(100k+1k)≈0.990，极点约 1/[2π(1k∥100k)C]：10 nF 时 16.1 kHz，换成 100 nF 后约 1.61 kHz。此为理想元件计算，不是实测带宽；低阻负载会改变响应。本例用于软件复现，不接市电、高压或产品负载。

## 干净起始资料

1. 在 Alpha 安装验收后，由操作者在嘉立创专业版 4.1.60 创建一个全新的本地单 Board 空白工程，保留单页原理图与空 PCB，另存为 `blank.eprj2`，保存并关闭。不要复制历史成品再删除图元伪装空白。
2. 原模板不得包含元件、连线、板框或铜对象。`create_work_project` 会复制模板并读回空白资格；失败时检查具体残留，重新创建干净模板，不修改核心代码绕过。
3. 选一个新的工作根目录，例如自己项目下 `rc-filter-run/`，使用尚不存在的 `initial/`、`modified/`、`manufacturing/` 输出目录。模板与工作输出分离。每次复现生成自己的 requestId、内部身份和工作记录。
4. 只读取现场库模型，不随公开仓库携带原生库文件。复现结束若计划公开实际图纸/截图/模型，先单独核实许可和脱敏。

## 对助手的起始提示

> 使用嘉立创 EDA 助手，按本目录 RC 需求从我提供的全新 blank.eprj2 创建独立小板。先核对实际 Alpha 版本、模板空白和真实器件/全部引脚模型，再绘制原理图和 PCB，完成逻辑、铜连通、严格 DRC、原生预览和完整保存。保存关闭后，从成品及其真实 checkpoint 派生新副本，将 C1 真实换料为相同符号/封装几何的 100 nF MLCC，保持其他内容，再检查保存并生成新的本地制造交付。只生成本地文件。

## 执行与验收顺序

1. doctor 为 `0.11.0-alpha.1 / 35`，确认客户端和宿主界面能力；现场选型，读取完整符号/封装和实际脚号。记录模型原点、两面方向、焊盘及端子身份。
2. create_work_project → draw_schematic → verify/preview。按输入到输出排列，电容与泄放支路向地，端点图应为 8 件/13 引脚/3 网；清楚标注 IN/OUT/GND。
3. sync_pcb 一次，在精确窗口复核导入。全部同步与网络验证完成后进入布局、规则与受限铜连接。建议 R1/C1 靠近、GND 路径短、测试点可触及，标签不压焊盘。初始线宽/间距目标 0.25/0.20 mm、板边 ≥0.30 mm；以实际模型和原生规则校验通过为准。必要时用普通通孔换层，绝不以飞线数冒充连接。
4. 现场全 pin→net→pad、全铜连通、严格 DRC 零项、原理图/PCB 视觉分别通过。finish 完成两端保存、全新磁盘副本完整核对和自有窗口关闭，保存初始成品与 checkpoint SHA。
5. 用 schematic_eco `mode=passives` 从 closed 初始成品正式派生到 `modified/`。对 C1 选 100 nF 实际兼容料号，prepare_replace → 原生器件管理器 → adopt_replace；保留位号/唯一身份/当前符号与封装，核对料号、值和 BOM。单次同步复核、complete/verify/finish。器件数/引脚数/网络、其他元件/铜/规则保持，原模板和初始成品 SHA 保持。若几何不兼容则另选真实候选，不能只改显示值。
6. 从最终成品 export_manufacturing 到新的目录；核对 Gerber/BOM/CPL、板框、13 焊盘/脚号映射、实际孔数、8 件数量、C1=100 nF、文字净距和方向。保存 manifest/SHA，报告所有覆盖缺口。文件生成与可制造/可装配分别给结论；3D、实物性能不在本轮软件资格内。

## 失败后的下一步与证据

缺少界面能力时，操作者只做工具指出的准确原生步骤，再以同请求验证。库模型读取受阻时先在正确窗口打开目标模型；不猜几何。unknown/pending 时保留状态，先只读诊断，不重复导入或换 requestId。连接/DRC 不通过时只处理已定位问题，保留失败记录；不重构整板掩盖原因。

保存：版本与环境、模板 SHA、真实选型证据、全部输入与回执、原生预览、全连接/严格 DRC、完整保存新磁盘比对、修改前后差异、成品与制造清单 SHA、窗口回收证明。预览/日志提交公共仓库前再次脱敏并核实分发权。第二轮须在不临时修改核心代码的前提下完成；若暴露缺陷，明确转为修复并重新标识验证范围。
